# Larissa Mendes | Fisioterapia domiciliar

Site institucional com abertura cinematográfica controlada pela rolagem, apresentação da profissional, informações sobre os benefícios da fisioterapia e formulário de agendamento via WhatsApp.

## Abrir localmente

Com Python instalado, execute na pasta do site:

```powershell
python -m http.server 4173
```

Acesse http://localhost:4173.

## Agendamento

O formulário reúne nome, região, motivo do atendimento e horários de preferência em uma mensagem para o WhatsApp configurado em `config.js`. A pessoa revisa e envia pelo próprio WhatsApp.

## Publicação

Este repositório contém os arquivos estáticos do site. GitHub Pages ainda não está habilitado.
